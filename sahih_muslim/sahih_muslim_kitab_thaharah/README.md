# Kitab Thaharah - Sahih Muslim

## Overview
This directory contains the complete implementation for Kitab Thaharah (Book of Purification) from Sahih Muslim, following the same structure and design patterns as the existing Sahih Bukhari implementation. The content is based on 16 videos from the YouTube channel: https://www.youtube.com/@muslimthaharah

## Structure
- `index.html` - Main grid view page for Kitab Thaharah sessions with enhanced Material Design
- `session1.html` through `session16.html` - Individual session pages with embedded YouTube videos
- `channel_data.json` - JSON data file containing all session information
- `video_data.txt` - Mapping of video IDs to titles
- `ytid.txt` - Simple list of YouTube video IDs

## Features
- ✅ Enhanced grid-based interface with Material Design components and YouTube thumbnails
- ✅ Responsive design that works on desktop and mobile devices
- ✅ Search functionality to filter sessions
- ✅ Theme support (light/dark mode)
- ✅ Navigation between sessions
- ✅ YouTube video integration with 16 real videos from the channel

## Implementation Details
The implementation was automatically generated using the channel processing tools and then enhanced with Material Design styling:
1. Uses the unified CSS theme for consistency
2. Implements an enhanced grid-based layout with thumbnails like other modules
3. Follows the same color scheme and styling
4. Uses Material Icons for visual elements
5. Includes responsive design for all screen sizes
6. Automatically generates session pages with embedded YouTube videos

## Content
The module includes 16 sessions covering various aspects of Kitab Thaharah, including:
- Kesesuaian & Pertalian Antara Kitab Iman & Kitab Thaharah
- Sesiapa Berwudhu` Sempurna Kemudian Solat,Akan Diampunkan Dosa Antara 2 Solat
- Sifat-Sifat Wudhu' Nabi s.a.w.
- Siwak
- Istiqabah (Menggunakan Air Untuk Beristinja')
- Menyapu Di Atas Dua Khuf
- Menetapkan Tempoh Menyapu Di Atas Khuf & Jilatan Anjing
- Larangan Kencing Dalam Air Yang Tidak Mengalir
- Cara Membasuh Darah Haidh Yang Terkena Kain
- Kitab Haidh (Menggauli Orang Berhaidh Di Atas Kainnya)
- Bab - Mazi
- Sifat mani lelaki dan wanita & anak tercipta drp mani kedua-duanya
- Elok Curahkan Air Atas Kepala & Bahagian Tubuh Yang Lain Sebanyak 3 Kali
- Mandi Dan Solat Orang Yang Istihadhah & Orang Haidh Wajib Gantikan Puasa
- Wajib Mandi Kerana Keluar Air Mani
