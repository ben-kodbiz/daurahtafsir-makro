# Sunan Abi Daud

This directory contains the implementation of Sunan Abi Daud, one of the important collections of Hadith literature. Sunan Abi Daud is one of the Sunan collections that, along with Sunan al-Tirmidhi, Sunan al-Nasa'i, and Sunan Ibn Majah, forms the group known as "Al-Sunan Al-Arba'ah" (The Four Sunan Collections).

## Structure

- `index.html` - Main page listing all kitabs
- `KITAB_TRACKING.md` - Tracking implementation progress
- `kitab_list.json` - List of all kitabs
- `Mukaddimah/` - Introduction to Sunan Abi Daud (In Progress)
- Individual kitab directories (to be created as implemented)

## Implementation Status

Currently, the implementation is in the planning phase, with Mukaddimah as the first kitab in progress. See [KITAB_TRACKING.md](KITAB_TRACKING.md) for detailed progress tracking.
