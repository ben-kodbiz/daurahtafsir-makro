# Kitab Iman - Sahih Muslim

## Overview
This directory contains the complete implementation for Kitab Iman (Book of Faith/Belief) from Sahih Muslim, following the same structure and design patterns as the existing Sahih Bukhari implementation. The content is based on 64 videos from the YouTube channel: https://www.youtube.com/@sahihmuslim-kitabiman-maul31

## Structure
- `index.html` - Main grid view page for Kitab Iman sessions with enhanced Material Design
- `session1.html` through `session64.html` - Individual session pages with embedded YouTube videos
- `channel_data.json` - JSON data file containing all session information
- `video_data.txt` - Mapping of video IDs to titles
- `ytid.txt` - Simple list of YouTube video IDs

## Features
- ✅ Enhanced grid-based interface with Material Design components and YouTube thumbnails
- ✅ Responsive design that works on desktop and mobile devices
- ✅ Search functionality to filter sessions
- ✅ Theme support (light/dark mode)
- ✅ Navigation between sessions
- ✅ YouTube video integration with 64 real videos from the channel

## Implementation Details
The implementation was automatically generated using the channel processing tools and then enhanced with Material Design styling:
1. Uses the unified CSS theme for consistency
2. Implements an enhanced grid-based layout with thumbnails like other modules
3. Follows the same color scheme and styling
4. Uses Material Icons for visual elements
5. Includes responsive design for all screen sizes
6. Automatically generates session pages with embedded YouTube videos

## Content
The module includes 64 sessions covering various aspects of Kitab Iman, including:
- Iman, Islam, Ihsan and their obligations
- The nature of faith and explanation of its components
- Signs of the Day of Judgment
- Various hadith about faith and belief
- And many more topics from the Book of Faith in Sahih Muslim

## Files Generated
- 64 session HTML files with embedded YouTube videos
- 1 main index file with enhanced searchable session grid and thumbnails
- 1 JSON data file with session information
- 1 video data file with YouTube IDs and titles
- 1 ytid file with simple list of video IDs

## Access
This module can be accessed from the main Sahih Muslim landing page by clicking on the "Kitab Iman" card.
