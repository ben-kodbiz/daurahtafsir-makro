# Kitab Haji - Sahih Muslim

## Overview
This directory contains the complete implementation for Kitab Haji (Book of Pilgrimage) from Sahih Muslim, following the same structure and design patterns as the existing Sahih Bukhari implementation. The content is based on 76 videos from the YouTube channel: https://www.youtube.com/@sahihmuslim-kitabhaji-maul3178

## Structure
- `index.html` - Main grid view page for Kitab Haji sessions with enhanced Material Design
- `session1.html` through `session76.html` - Individual session pages with embedded YouTube videos
- `channel_data.json` - JSON data file containing all session information
- `video_data.txt` - Mapping of video IDs to titles
- `ytid.txt` - Simple list of YouTube video IDs

## Features
- ✅ Enhanced grid-based interface with Material Design components and YouTube thumbnails
- ✅ Responsive design that works on desktop and mobile devices
- ✅ Search functionality to filter sessions
- ✅ Theme support (light/dark mode)
- ✅ Navigation between sessions
- ✅ YouTube video integration with 76 real videos from the channel

## Implementation Details
The implementation was automatically generated using the channel processing tools and then enhanced with Material Design styling:
1. Uses the unified CSS theme for consistency
2. Implements an enhanced grid-based layout with thumbnails like other modules
3. Follows the same color scheme and styling
4. Uses Material Icons for visual elements
5. Includes responsive design for all screen sizes
6. Automatically generates session pages with embedded YouTube videos
